# Передача работы новой сессии (DocuView / SaasProject_v2)

Этот файл — всё, что нужно новой сессии Claude, чтобы продолжить с того же
места. Новая сессия должна работать **локально на ПК пользователя (Windows)**.

## 1. Задача пользователя

- SaaS-просмотрщик CAD/PDF/Office в браузере (DocuView).
- Главное: **открывать модели SOLIDWORKS в браузере в 3D без какого-либо CAD
  на ПК**. Сначала — 100% любых `.SLDPRT`.
- Программа должна лежать в `C:\User\SaaS\SaasProject_v2\`, запуск одним
  кликом: **`C:\User\SaaS\SaasProject_v2\Start-DocuView.bat`** (поднимает всё
  в фоне и открывает браузер).
- Примеры моделей пользователя: `C:\User\3D\SW\`.
- Пользователь пишет по-русски, отвечать по-русски, коротко и по делу.

## 2. Первое, что сделать (локально)

1. Склонировать `https://github.com/kipniss94/SaasProject_1` (ветка `main`)
   **прямо в** `C:\User\SaaS\SaasProject_v2` (содержимое репозитория — в корне
   этой папки, без вложенной `SaasProject_1-main`). Репозиторий приватный —
   git попросит вход в GitHub.
   Зеркало кода: `kipniss94/my-first-pr`, ветка `claude/cad-pdf-office-saas-06j0zk`.
2. Запустить `Start-DocuView.bat`. Первый запуск: `npm install` + production-сборка
   (3–8 мин), затем открывается `http://127.0.0.1:3000`. Нужен Node.js ≥ 20.11
   (если нет — бат откроет nodejs.org).
3. При запущенном просмотрщике запустить `Check-All-Models.bat` (по умолчанию
   проверяет `C:\User\3D\SW`). Ожидается 100% непустых `.SLDPRT` в 3D.
   Отчёт HTML/CSV — в `logs\`.
4. Показать пользователю путь к бату и итог отчёта.

## 3. Что уже сделано и проверено

**Формат `.SLDPRT` (современный SolidWorks) разобран полностью:**

- Это **ZIP без сигнатур `PK\x03\x04`**. Локальный заголовок начинается с
  `14 00` (версия 2.0), `06 00` (флаги), `08 00` (deflate), время, дата, CRC-32,
  размеры, длины имени/extra. Имена записаны с **перестановкой полубайтов**
  (`((b&0x0f)<<4)|(b>>4)`). Каждую запись проверяем: raw-inflate → длина и
  CRC-32 должны совпасть. Код: `apps/api/src/processing/sldprt/container.ts`
  (`readPackage`, `unwrapCodec`, `findPreviewPng`, `findModelPartition`).
- `Contents/DisplayLists` — MFC-архив (`uoTempBodyTessData_c`,
  `uoTempFaceTessData_c`) с **готовой триангуляцией SolidWorks**. Каждая грань:
  `4,8,2,<число стрипов>,<длины стрипов…>` (u32 LE), затем
  `12,100,2,<n>` + n×xyz float32 LE (метры, позиции), затем `12,100,2,<n>` +
  n×xyz (нормали). Сумма длин стрипов = n. Треугольники ориентируются по
  нормалям. Код: `apps/api/src/processing/sldprt/display-list.ts`.
- `Contents/Config-*-Partition` — внутри GUID `231dd571da8148a2a85898b21b89ef99`,
  затем `u32 размер`, `u32 сжатый размер`, zlib → **Parasolid XT** (точная
  B-rep, big-endian doubles). Отдаётся на скачивание как `geometry.x_t`.
- `PreviewPNG` — обычный PNG-превью.

**Проверки (без CAD):**
- 132 из 132 непустых деталей корпуса → закрытая сетка, объём > 0; 5 файлов
  по 0 байт — пустые.
- Объём: куб 10 мм = 1000 мм³ точно, куб 20 = 8000, лист 50×100×2 = 10000,
  цилиндр Ø50×100 −0,3% (фасеты).
- В реальном браузере (Playwright) `юбка`, `регуль`, `BT100.01.01.201`,
  `hobbywing 56118 (3)` совпадают с превью SolidWorks.
- `npm test` — 55/55, typecheck и lint чистые.

**Ошибка, которую уже исправили (не повторять):** раньше утверждалось, что ~35%
файлов «закрыты кодеком». Это неправда — артефакт побайтового поиска zlib.
Читать только как ZIP-записи с проверкой CRC.

## 4. Устройство проекта

- npm workspaces: `packages/shared`, `apps/api` (Express 5, порт 4000),
  `apps/web` (Next.js 15, порт 3000). Веб проксирует `/api/v1/*` на API.
- Обработка SLDPRT: `apps/api/src/processing/processors/cad-proprietary.ts` —
  сначала сетка из файла → NMG (`writeNmg` из `cad-occt.ts`) → `viewer: cad-nmg`;
  если сетки нет (сборки `.SLDASM`) → превью/свойства. `CAD_CONVERTER_CMD` —
  необязательный запасной путь, по умолчанию не используется.
- Запуск на Windows: `Start-DocuView.bat` → `tools/launcher.mjs` (Node):
  npm install при смене package-lock, сборка при смене исходников (отпечаток
  берётся ПОСЛЕ сборки), API+веб в фоне на 127.0.0.1, логи в `logs\`,
  клавиши O (браузер) / S (стоп). `Stop-DocuView.bat`, `Check-All-Models.bat` →
  `scripts/verify-models.mjs`. Инструкция пользователю: `START-HERE.md`.
- Исследовательские заметки: `docs/sldprt/01-container.md`, `02-parasolid.md`,
  `03-display-mesh.md`.

## 5. Ограничения, которые нужно соблюдать

- **Никакого CAD** (SOLIDWORKS не использовать, конвертер на нём удалён).
- **Не обходить защиту Windows**: без `-ExecutionPolicy Bypass`, без скриптов
  PowerShell в пользовательском сценарии, без тихих установок.
- `.bat` — только ASCII (кириллица ломает cmd.exe); русский текст выводит Node.
- В `Playwright` путь к файлу с кириллицей через `setInputFiles` не работает —
  это баг тестового инструмента, не приложения; тестировать через drop.
- Модели пользователя в git не коммитить (`samples/` в .gitignore). Для тестов
  положить `.SLDPRT` в `samples/` (например, из `C:\User\3D\SW`).
- Коммиты: осмысленные сообщения; пушить в `SaasProject_1` main и в зеркало.

## 6. Что дальше (по приоритету)

1. Развернуть на ПК, прогнать `Check-All-Models.bat` по `C:\User\3D\SW`; если

   и матрицы размещения — найти их в записях сборки и собрать модель из деталей.
3. Цвет деталей (appearance из SolidWorks) вместо серого.
