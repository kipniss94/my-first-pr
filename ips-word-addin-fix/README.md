# Исправление установки надстройки IPS для Word

Скрипт исправляет ошибку установки `IPSWordAddIn.vsto`:

> Ссылка в развертывании не соответствует удостоверению, определенному в манифесте приложения.
> (System.Deployment.Application.InvalidDeploymentException)

## Как запустить

1. Скачайте папку `ips-word-addin-fix` целиком: `fix-ips-word-addin.ps1` и `run-fix.cmd` должны лежать рядом.
2. Закройте Word.
3. Дважды щёлкните `run-fix.cmd`. Права администратора не нужны: запускайте под тем пользователем, у которого должна работать надстройка.
4. Отвечайте на вопросы скрипта. Если Word спросит про издателя надстройки, нажмите «Установить».

По умолчанию дистрибутив ищется в `C:\instal\IPS\10\IPS.Installer.Full`. Если он лежит в другом месте, скрипт спросит путь. Можно указать его и сразу:

```
run-fix.cmd -IpsPath "D:\Дистрибутивы\IPS\10\IPS.Installer.Full"
```

Только диагностика, без изменений:

```
run-fix.cmd -CheckOnly
```

## Что делает скрипт

1. Находит `IPSWordAddIn.vsto` (предпочтительно вариант из `Word2013`).
2. Сверяет ссылку в `.vsto` с удостоверением в `IPSWordAddIn.dll.manifest`: имя, версию, `publicKeyToken`, архитектуру. Если они расходятся, ошибка возникает именно из-за этого, и скрипт показывает, какое поле не совпало.
3. Проверяет .NET Framework, VSTO Runtime и `VSTOInstaller.exe`.
4. Закрывает Word, предварительно спросив.
5. Снимает с файлов дистрибутива блокировку «загружено из интернета».
6. Сохраняет резервную копию ключей реестра и удаляет прежнюю установку надстройки: ключи в `HKCU\...\Word\Addins`, `HKCU\...\VSTO\SolutionMetadata` и `HKCU\...\VSTO\Security\Inclusion`, а также онлайн-кэш ClickOnce.
7. Если манифесты в дистрибутиве не согласованы, по вашему согласию делает исправленную копию надстройки в `%LOCALAPPDATA%\IPSWordAddIn-repaired`. В копии ссылка в `.vsto` приводится к фактическому манифесту (как `mage.exe -Update`), а сам `.vsto` переподписывается локальным сертификатом.
8. Устанавливает надстройку через `VSTOInstaller` с подробным логом. Если установка снова не удалась, предлагает сбросить хранилище ClickOnce (`%LOCALAPPDATA%\Apps\2.0`). Папка не удаляется, а переименовывается, и её можно вернуть.

Лог работы, копии манифестов и резервная копия реестра сохраняются в папку `IPSWordAddIn-fix-<дата>` на Рабочем столе. Если не помогло, отправьте эту папку в поддержку IPS.

Восстановить реестр из резервной копии можно двойным щелчком по соответствующему `.reg` файлу из этой папки.
