# DocuView v2 — запуск на Windows

## Установка (один раз)

1. Скачайте архив репозитория: **Code → Download ZIP**.
2. Распакуйте его содержимое в `C:\User\SaaS\SaasProject_v2\` — так, чтобы
   `Start-DocuView.bat` лежал прямо в этой папке:

   ```
   C:\User\SaaS\SaasProject_v2\Start-DocuView.bat
   C:\User\SaaS\SaasProject_v2\package.json
   C:\User\SaaS\SaasProject_v2\apps\ ...
   ```

   Папка может быть любой — путь нигде не зашит.
3. Если SOLIDWORKS на этом ПК ещё ни разу не запускался под вашей учётной
   записью, откройте его один раз вручную и закройте: при первом запуске он
   спрашивает про лицензию, а в фоновом режиме спросить не сможет.

## Запуск

Двойной щелчок: **`C:\User\SaaS\SaasProject_v2\Start-DocuView.bat`**

Первый запуск: 3–8 минут (установка зависимостей и сборка), нужен интернет.
Все следующие — несколько секунд.

Когда всё готово, браузер откроется сам на `http://127.0.0.1:3000`.
Перетащите в окно `.SLDPRT` — модель откроется в 3D.

- **O** в окне запуска — открыть браузер ещё раз
- **S** или закрыть окно — остановить
- `Stop-DocuView.bat` — остановить, если окно уже закрыто

## Как открываются модели SOLIDWORKS

Просмотрщик находит установленный SOLIDWORKS и запускает его **скрыто, в
фоне**, как конвертер: SOLIDWORKS открывает файл и сохраняет его в STEP, а
дальше модель идёт в браузер обычным путём просмотрщика — вращение,
сечения, измерения. Человеку в браузере CAD не нужен.

Зачем нужен SOLIDWORKS на сервере: примерно у трети реальных деталей
геометрия внутри файла закрыта кодеком, который открывает только сам
SOLIDWORKS. Без него просмотрщик читает остальные собственными силами, но
100% даёт только этот путь.

- Первая модель после запуска открывается до минуты — SOLIDWORKS прогревается.
  Дальше — секунды на деталь.
- Если у вас уже открыт свой SOLIDWORKS, просмотрщик работает через него
  и **не закрывает** его. Закрывает только тот, что запустил сам.
- Сборки `.SLDASM` тоже открываются, если детали лежат там, где сборка их
  ожидает (например, в `C:\User\3D\SW\`).

## Проверка: открываются ли все модели

При запущенном просмотрщике дважды щёлкните **`Check-All-Models.bat`**.

Он прогоняет все `.SLDPRT` из `C:\User\3D\SW\` (и подпапок) через просмотрщик
так же, как браузер, и открывает отчёт: сколько моделей открылось в 3D, время
на каждую, причина для каждой неоткрывшейся. Отчёт сохраняется в `logs\`.

Другая папка или вместе со сборками — из командной строки:

```
Check-All-Models.bat "D:\Модели"
Check-All-Models.bat "C:\User\3D\SW" --assemblies
```

Файлы размером 0 байт в отчёте отмечены как «пустой файл»: модели в них нет,
открыть их не может никто, включая сам SOLIDWORKS.

## Если что-то пошло не так

Окно запуска пишет причину и не закрывается. Подробные логи — в папке `logs\`:

| файл | что там |
| --- | --- |
| `install.log` | установка зависимостей |
| `build.log` | сборка |
| `helper-build.log` | сборка помощника SOLIDWORKS |
| `solidworks.log` | каждая конвертация: что, сколько весило, сколько секунд |
| `api-*.log`, `web-*.log` | работа серверов |

Пришлите нужный лог — по нему видно, что случилось.

Частые случаи:

- **«Node.js is not installed»** — откроется страница загрузки; поставьте LTS
  и запустите снова.
- **«Порт 3000 или 4000 занят»** — окно назовёт программу, которая его держит.
- **«SOLIDWORKS не найден»** — просмотрщик работает, но без 3D у части файлов.
- **Модель в отчёте «ошибка» с текстом про «newer SOLIDWORKS»** — файл
  сохранён более новой версией SOLIDWORKS, чем установлена здесь.

## Что внутри

| | |
| --- | --- |
| `Start-DocuView.bat`, `Stop-DocuView.bat`, `Check-All-Models.bat` | запуск, остановка, проверка |
| `tools\launcher.mjs` | всё, что делает запуск |
| `tools\solidworks\SwConvert.cs` | мост к SOLIDWORKS; компилируется при первом запуске встроенным в Windows компилятором C# |
| `tools\solidworks\convert.mjs` | готовит файл и вызывает мост |
| `scripts\verify-models.mjs` | проверка всех моделей |

Никаких скриптов PowerShell: Windows по умолчанию запрещает их запуск, и
обходить эту защиту просмотрщик не должен.
