# Скрипты C# для IPS (Интермех)

Пользователь — администратор IPS (ОДО «ИНТЕРМЕХ»), пишет по-русски. Отвечать по-русски, кратко.

## Правила работы
- Исходный скрипт пользователя сохранять как «Имя rev1.cs», исправленный — «Имя rev2.cs» (rev3… далее).
- Правки минимальные и точечные; не переписывать работающую логику без нужды. После правки
  проверять, что ни один метод не потерян.
- Перед сдачей: компиляция на заглушках (tools/stubs), прогон изменённой логики, проверка
  отсутствия статических полей. Сообщать, что проверено, а что нет (настоящих сборок IPS нет).
- Не угадывать API: если имя члена не подтверждено — писать компиляционно-безопасный код
  (reflection, сравнение по имени) и говорить об этом.

## Ограничения IPS (проверено на практике)
- В скрипте запрещены статические поля и статические свойства с записью
  (ScriptAssemblyChecker). Статические методы и const — можно.
- Отчёты (Execute(IUserSession, ImDocumentData, Int64[]) → ScriptResult) компилируются и
  выполняются НА СЕРВЕРЕ (DBReportScenario): нет System.Windows.Forms, нет клиентских сборок
  (Intermech.Project.Client, ProjectEditorForm, MessageBox).
- Скрипты кнопок форм (Execute(AttributeValidationScriptParameters)) компилируются на клиенте.
- Работа с объектами после возврата из Execute (немодальные окна) — только внутри
  using (SessionKeeper keeper = new SessionKeeper()) { keeper.Session … }.
- session.GetObject(id) при отсутствии объекта бросает исключение, а не возвращает null.
- Атрибуты «может быть добавлен вручную» отсутствуют у объекта, пока не заполнены:
  GetAttributeByGuid вернёт null.
- MetaDataHelper.GetRelationTypeIDFromName не существует; есть GetRelationTypeID(guid),
  GetRelationTypeName(id), GetObjectTypeIDFromName(name), GetObjectTypeName(id).
- В новой версии на сервере нет DayType.Holyday — сравнивать тип дня по имени.
- IDBObject.ObjectID — идентификатор версии объекта (ссылка ips://object/<id>); ObjectType — id типа.
- Ссылка на объект в обсуждениях: [ref="<ObjectGUID>"]текст[/ref].
- «Напомнить за (интервал)» скриптом не пишется (IPS отклоняет) — заполняется по умолчанию.
